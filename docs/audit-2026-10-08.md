# Code and repository audit — 8 October 2026

Evaluation: predictions consume prices through the forecast origin; scored endpoints are bounded by the stage; MASE uses the initial training slice. Relative MAE now uses the same origins as persistence. Historical prices were inspected, so this is not a blind prospective analysis.

Regimes: thresholds use training observations only; each origin uses trailing Low log changes through that origin. Invalid/non-finite prices and insufficient history are rejected. Low volatility is not close-return volatility.

Intervals: evaluation actuals are available offline for scoring, but pending feedback is released only at origin+h. Warm residuals must already have matured. The saved original attention notebook is not certified by this audit.

Statistics: resampling rejects non-finite values; block length remains an assumption requiring sensitivity. DM now retains a positive automatic HAC bandwidth at h=1 and uses at least h−1 lags. [Primary implementation reference](https://www.statsmodels.org/stable/generated/statsmodels.stats.sandwich_covariance.cov_hac.html). Coverage likelihood tests are diagnostics with assumptions, not financial-market coverage guarantees. No formal proof or complete independent review is claimed.

Repository policy rejects vendor files under any data/raw directory, including legacy. Removing files from main does not remove historical Git objects. Locked BTC metadata is public; raw snapshot is local, and exact-hash restoration can fail if Yahoo revises history.
