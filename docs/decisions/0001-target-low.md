# ADR 0001: daily Low as the initial target

Decision date: 8 October 2026. Status: accepted for foundation v1.

Retain BTC-USD daily Low because the original attention notebook forecasts this quantity
and the applicant can explain that workflow. This preserves continuity between practical
preparation and the research question.

Close is easier to interpret as a daily reference price, but moving to it would create
a different experiment. It can be a later predeclared sensitivity study. FRED spot price
must not be relabelled as Yahoo daily Low. Forecast metrics are not trading-profit evidence.
