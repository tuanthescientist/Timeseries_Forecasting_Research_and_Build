# Data card

## Included: synthetic demo

`demo/synthetic_prices.csv` contains 600 daily observations beginning on 2020-01-01,
generated by `scripts/make_demo_data.py` using Python's seeded pseudorandom generator
(`42`). Prices evolve multiplicatively with Gaussian innovations, a sinusoidal term,
and a change in drift after observation 300. Values are rounded to eight decimals.

This is artificial data created for testing. It contains no observed market prices,
individual records, trading signals, or personal data. Its patterns were specified by
the generator; performance on it says nothing about financial-market predictability.
The exact input hash is saved with the demo results.

## Local market data

Use `raw/` for your own licensed or otherwise authorized datasets. Files there are
ignored by Git. Original local Bitcoin, BNB, and VN30 snapshots were not copied into
this public repository because their provenance and redistribution terms were not
sufficiently documented. Some exploratory notebooks fetch data at runtime; those
responses can change and are not immutable experiment inputs.

Before reporting results, record:

| Field | Required information |
| --- | --- |
| Instrument and provider | Symbol, exchange/index, provider, source URL |
| Target and units | Low/close/high, quote currency, adjusted/unadjusted |
| Time | Frequency, time zone, timestamp convention, session calendar |
| Snapshot | Retrieval date, first/last observation, row count, SHA-256 |
| Processing | Duplicates, missing data, sorting, transformations |
| Usage rights | License or relevant provider terms; redistribution permission |
| Evaluation | Development/calibration/final periods and eligible origins |

The core accepts explicit `ds,y` CSVs. Historical VN30 notebooks expect their original
OHLCV schemas, so a core-ready CSV is not automatically interchangeable with them.
