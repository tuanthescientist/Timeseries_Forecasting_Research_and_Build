# Literature reading map

The [full bibliography](https://github.com/tuanthescientist/Timeseries_Forecasting_Research_and_Build/blob/main/legacy/docs/proposals/PhD_Research_Proposal.md#references) contains 23 sources. Numbers below refer to that bibliography.

| Priority | Sources | Research decision |
| --- | --- | --- |
| Evaluation fundamentals | [1]–[4] | Chronological selection, matching tasks, scaling and complete reporting |
| Financial benchmarks | [10], [11] | Persistence/drift first; negative findings retained |
| Model components | [12]–[14] | Explain NeuralProphet, attention and ExtraTrees; distinguish implementation and novelty |
| Statistical comparisons | [5]–[9] | Dependent losses, small-sample limits and controlled comparison families |
| Interval scoring and conformal basics | [15]–[17] | Assess coverage, width and interval score together |
| Limits and changing distributions | [18], [19] | Predefined regime evaluation with explicit assumptions |
| Sequential competitors | [20]–[23] | Compare established methods and delayed feedback before proposing an extension |

Begin with [Forecasting: Principles and Practice](https://otexts.com/fpp3/) and the [evaluation review](https://arxiv.org/abs/2203.10716). For interval research, read the [conformal introduction](https://arxiv.org/abs/2107.07511), then [ACI](https://arxiv.org/abs/2106.00170), [EnbPI](https://proceedings.mlr.press/v139/xu21h.html), [adaptive aggregation](https://proceedings.mlr.press/v162/zaffran22a.html) and the [2024 online extension](https://jmlr.org/papers/v25/22-1218.html).

This selected bibliography is a starting point for a continuing doctoral review. It does not imply that every cited method is implemented in the repository.
